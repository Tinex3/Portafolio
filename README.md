# Portafolio de Benjamin Riquelme

Portafolio profesional de Benjamin Delfin Riquelme Gomez, desarrollador Full Stack e IoT de Vina del Mar, Chile.

## Stack

- React 19, TypeScript y Vite
- Tailwind CSS 4
- Nginx para servir la SPA
- Docker y Docker Compose

## Desarrollo local

```bash
npm install
npm run dev
```

## Verificaciones

```bash
npm run lint
npm run build
```

## Docker

```bash
docker compose up -d --build
```

La aplicación queda disponible en `http://localhost:5876`.
